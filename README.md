# Design-implement-and-comparative-analysis-of-D-flip-flop
Designed and simulated five CMOS master–slave D flip-flop architectures using DSCH and Microwind. Compared power, delay, PDP, and transistor count. Achieved 12.49 µW power and 49.5 ps delay in NOR-based design. Identified TG-based design with minimum 18 transistors.
